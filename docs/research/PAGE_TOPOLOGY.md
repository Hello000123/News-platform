# Page Topology

## Reference topology

1. Fixed utility header and horizontally clipped tag navigation — static while scrolling.
2. Archive masthead — category dot plus a single `h1`.
3. Article archive — repeated image/content rows with category, title, age, and share affordance.
4. Pagination — previous, numbered pages, next.
5. Mobile menu overlay — click-driven, full viewport.
6. Cookie notification — fixed overlay; not part of the PressReady adaptation.

## PressReady homepage topology

1. Existing utility strip and masthead — current brand, edition date, public category navigation, and admin shortcuts.
2. Existing topic rail — now links to the two durable category archives.
3. Lead report — image-led two-column editorial story with headline, deck, metadata, and compact supporting reports.
4. Technology shelf — category masthead, one featured report, and supporting image-led rows.
5. Social enterprise shelf — same component contract with independent content.
6. Latest stream — dense chronological list of all approved posts.
7. Existing editorial footer — adds durable category links.

## Category archive topology

1. Shared public header.
2. Category masthead with gold marker, Traditional Chinese title, description, and story count.
3. Image-led article rows derived from the reference layout but using PressReady tokens.
4. Empty state when no approved posts belong to the category.
5. Shared public footer.

## Editorial composer topology

1. Source context.
2. Public headline and category controls.
3. Featured image upload, preview, replace/remove actions, and advanced URL fallback.
4. Editable article body.
5. Rewrite actions and validation feedback.
6. Save, publish/update, preview, and unpublish controls.
